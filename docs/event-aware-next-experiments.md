# 연구계획서 보강: 이벤트 배분과 내부 선택을 분리하는 다음 실험

작성일: 2026-09-20. 연구계획서 PDF와 현재 구현, 60영상·180문항 dev 결과를 검토한 제안이다. 3절의 A/B/C/D 실행기는 `event_caption_pilot.event_factorial_dev`에 구현했고, 실행 방법은 [event-factorial-run.md](event-factorial-run.md)에 정리했다. 새 성능 실험은 아직 실행하지 않았으며 나머지 확장 단계는 제안이다. 원본 PDF는 수정하지 않았다.

## 1. 연구 질문을 좁히기

권장 중심 질문:

> 동일한 관측 후보와 최종 입력 예산에서, 내용 변화에 따른 구간화가 단순한 시간 분산보다 답의 근거를 더 잘 보존하는가? 질문 관련성은 구간별 프레임 수 배분과 구간 내부 선택 중 어디에서 도움이 되는가?

계획서의 RQ4와 RQ6, 2.6 Event-Aware Token Allocation, 2.7 Within-Event Frame Selection, 4.5 Experiment 2/4/5를 먼저 실행한다. 복잡도 결합, 캡션, 계층 구조, 불확실성 기반 재배분은 뒤에 둔다. 효과가 나오도록 조건을 계속 늘리는 대신, 긍정·부정 결과 모두 병목을 설명할 수 있도록 비교를 구성한다.

현재 결과:

| 조건 | 정확도 | Uniform 대비 차이 및 영상 단위 95% CI |
|---|---:|---:|
| Uniform | 48.61% | 기준 |
| Global TOP | 47.31% | -1.30%p [-5.74, +2.96] |
| Temporal BIN | 49.35% | +0.74%p [-2.50, +3.80] |

현재 CLIP 질문 유사도와 16장, 고정 로그우도 QA 조건에서 개선 근거가 확보되지 않았다. 동등성을 입증한 결과도, 이벤트 방법을 반박한 결과도 아니다. BIN이 TOP보다 높은 평균을 보인 것은 시간적 분산에 관한 가설의 출발점이며 원인 증명은 아니다.

## 2. 계획서와 구현의 차이

| 요소 | 계획서 | 현재 코드와 완료 실험 |
|---|---|---|
| 구간화 | 인접/윈도 특징 변화, 국소 최대, 최소 길이 | algorithms.segment의 D1/D2 존재. D2는 윈도 평균 간 cosine distance를 점수순으로 선택하고 최소 간격 적용. 명시적 국소 최대 필터·유사도 병합과는 다름 |
| 구간 특징 | mean pooling을 기본으로 확장 비교 | 기존 event pipeline에 정규화된 평균 특징 존재 |
| 중요도 | relevance + complexity | 기존 event pipeline은 V/T/V+T. 계획서의 motion/diversity/variance 결합과 다름 |
| 배분 | softmax, 최소 배분, 명시적 sparse 정책 | capacity를 지키는 softmax와 잔여량 배분 존재. 반올림으로 0장이 되는 것과 명시적 sparse threshold 정책은 구분 필요 |
| 구간 내부 선택 | 관련성·다양성을 함께 고려 | 기존 event pipeline은 구간 내부 균등 선택. Global TOP/BIN은 별도 프레임 대조군 |
| 완료된 180문항 실험 | 전체 event-aware framework 검증 필요 | selection_dev는 Uniform/TOP/BIN 세 조건만 평가 |

따라서 기존 코드를 그대로 실행하는 것으로 계획서 전체가 검증되지는 않는다. PDF의 semantic event 표현도 현재 비학습 CLIP 변화점이 사람의 의미적 사건 경계와 같다는 보장은 없으므로, 실험에서는 '내용 변화 기반 구간'이라고 정확히 기술한다.

## 3. 다음 실행: 구간화 × 배분의 2×2 비교

최종 16장, 후보 2fps·224×224, 같은 CLIP, Qwen 체크포인트, QA 프롬프트, 로그우도 채점, 문항별 같은 6개 선택지 순서를 유지한다. 관련성은 질문 텍스트만 이용한다.

각 영상에서 D2 구간 수 K를 구하고, D0도 같은 K개의 균등 구간을 만든다. 기존 BIN의 16개 구간과 새 D0의 K개 구간은 서로 다르다.

| 조건 | 구간 경계 | 구간별 프레임 수 배분 | 구간 내부 선택 |
|---|---|---|---|
| A | D0, D2와 K 일치 | 구간 후보 수에 비례 | 균등 |
| B | D2 | 구간 후보 수에 비례 | 균등 |
| C | D0, D2와 K 일치 | 질문 관련성 softmax | 균등 |
| D | D2 | 질문 관련성 softmax | 균등 |

구간 후보 수 비례는 현재 고정 FPS 후보에서 지속시간 비례의 근사다. 불규칙 타임스탬프에는 두 개념을 혼용하지 않는다. capacity를 넘지 않는 정수 배분, 총 16장, 중복 없는 선택과 시간순 입력을 모두 보장한다. K>16인 경우 모든 구간에 최소 1장을 보장할 수 없으므로 이번 비교에는 그 제약을 넣지 않는다.

주 비교는 **D-C**로 사전 지정한다. 같은 relevance 배분 아래 내용 기반 구간화가 균등 구간화보다 유리한지 확인한다. 이는 구간 특징·길이 변화까지 포함한 구간화 정책의 효과이며, '경계 위치 정확도만의 효과'는 아니다.

보조 비교:

- B-A: 질문 기반 배분이 없을 때의 구간화 효과.
- C-A, D-B: 각 구간화에서 질문 기반 배분으로 바꾼 효과.
- (D-B)-(C-A): 구간화에 따라 질문 기반 배분의 효과가 달라지는지.
- D-Uniform, D-BIN: 기존 프레임 선택 대조군 대비 최종 효과.

180문항 × 4조건 × 6순서 = 4,320개의 새 QA 채점 호출이다. 각 호출은 기존 선택지별 점수 계산을 포함한다. 동일 입력이 발생하면 입력·모델·순서·프로토콜 해시가 완전히 일치할 때만 QA 결과를 재사용한다. 기존 Uniform/TOP/BIN도 같은 검증 후 재사용한다.

### 실행 전 저비용 점검

- 영상별 K, 구간 길이, 최대 구간 수 24 도달 비율, K=1 비율.
- softmax 점수 분포, 배분 엔트로피, 실제 정수 배분 벡터.
- 질문을 바꾸었을 때 배분이 바뀌는 비율 및 후보 프레임 중복률.
- 프레임 선택 규칙의 동점 처리와 정확한 budget 보존.

cosine 점수 차이가 작거나 정수 반올림으로 모든 질문의 배분이 같으면 질문 조건화가 거의 작동하지 않는 실험이 된다. QA 정답률을 보고 온도를 고르기 전에 이 작동 여부부터 확인한다. 점수 정규화와 온도는 dev에서 정의하고 이후 고정한다. 기존 V/T 교정값을 새로운 중요도 규칙에 무조건 재사용하지 않는다.

## 4. 다음 단계: 배분 × 내부 선택의 2×2 비교

하나의 명시된 구간화에서 다음 네 조건을 비교한다. 1단계 D2의 두 조건을 재사용할 수 있다.

| 구간별 배분 | 내부 균등 선택 | 내부 질문 TOP 선택 |
|---|---|---|
| 후보 수 비례 | 관련성 미사용 | 내부 선택에만 사용 |
| 질문 관련성 | 배분에만 사용 | 두 단계 모두 사용 |

내부 선택끼리 비교할 때는 같은 질문의 구간과 배분 벡터 n_k를 그대로 유지한다. 그래야 계획서 RQ4와 H8을 직접 평가할 수 있다.

다양성 선택은 별도 추가 비교로 둔다. 계획서 2.7.3의 '질문 관련성 - 이미 선택된 프레임과의 최대 유사도'를 적용할 수 있다. 이때 **구간 없이 동일한 다양성 선택을 적용하는 대조군**도 필요하다. 성능 향상이 이벤트 구조 때문인지 중복 제거 때문인지 구분하기 위해서다.

## 5. QA 정확도 외에 남길 진단 정보

- 문항별 정확도 차이와 개선/악화/동일 문항 수. 순서 반복은 독립 표본으로 세지 않는다.
- 동일 영상에 속한 문항과 조건을 함께 묶는 paired video bootstrap 5,000회.
- 선택 인덱스·타임스탬프·구간 ID·n_k·관련성 원점수·정규화 점수.
- 선택 프레임의 평균 특징 유사도, 고정 시간 구간 점유율, 최대 미관측 간격, 방법 간 중복률.
- 정답 근거가 주석된 문항에서 근거 구간 hit와 모든 필요 구간 hit. 원본 후보 풀의 hit도 함께 기록한다.
- 이미지 processor의 실제 visual token 수, 전체 입력 토큰 수, decode/CLIP/구간화/선택/QA 시간, peak GPU memory.

특징 유사도와 시간적 분산은 근거 보존의 대리 지표다. 실제 근거 주석 없이 evidence recall이라고 부르지 않는다. sparse 프레임 집합과 연속 시간 구간의 IoU도 자동으로 정의되지 않으므로, 관측 시간창 정의 없이 temporal IoU를 보고하지 않는다.

근거 주석은 방법별 예측을 가린 상태에서 원본 영상과 질문을 보고 작성한다. 모든 조건이 같은 주석으로 평가된다. 장면 전후 비교가 필요한 질문은 하나의 구간 hit만으로 충분하다고 처리하지 않는다. 2fps/224×224 후보에서 근거가 관측되지 않는 경우와 선택에서 탈락한 경우, 포함됐지만 QA가 틀린 경우를 구분한다. 해상도를 바꾸는 실험은 새 프로토콜로 모든 대조군을 다시 평가한다.

## 6. 계획서 자체에서 보강할 부분

### 6.1 frame budget과 visual token budget

현재 방법은 각 이미지 내부의 patch token 수를 직접 배분하지 않고 프레임 수를 배분한다. 고정 해상도·processor에서는 프레임 수가 visual token 수의 대리 지표가 될 수 있지만 실제 grid와 merge 규칙으로 확인해야 한다. 연구 제목/본문은 'event-aware frame allocation under a measured visual-token budget'처럼 실험 범위를 명확히 기술할 수 있다.

같은 16장 비교는 정확도 비교다. 효율 향상을 주장하려면 전처리까지 포함한 비용을 측정하고, B=8/16/32에서 정확도-비용 곡선을 제시한다. 단순 Acc/B는 적은 budget을 기계적으로 유리하게 만들 수 있어 주 효율 지표로 사용하지 않는다. 캐시 없는 최초 비용과 영상당 여러 질문에서 전처리를 공유한 비용을 따로 제시한다.

### 6.2 complexity의 중복 신호

계획서 2.5.2의 pairwise cosine diversity D와 feature variance V는 독립적인 정보라고 보기 어렵다. z_i가 단위 벡터이고 h가 재정규화하지 않은 산술 평균일 때, m>1에 대해 정확히 다음 관계가 성립한다.

`D = m / (m - 1) * V`

따라서 D와 V를 모두 넣으면 같은 분산 정보를 길이 의존 계수와 함께 중복 반영한다. 우선 인접 특징 변화 M과 분산 계열 한 항만 구분해 검증한다. M 역시 실제 물체 움직임만 측정하는 값은 아니므로 motion보다 adjacent feature change라는 명칭이 정확하다. m=1 처리도 사전 정의한다.

### 6.3 boundary F1과 QA의 관계

다른 데이터셋의 GEBD F1과 Video-MME QA를 나란히 제시하는 것만으로 영상별 관계를 직접 검증할 수 없다. 동일 QA 영상에 경계 주석이 있는 소규모 진단 세트가 필요하다. 주석이 없다면 구간 수/길이를 통제한 경계 이동, 병합, 분할에 대한 QA 민감도를 평가하되 boundary accuracy 효과로 단정하지 않는다.

구간 수를 맞춘 D0만으로 길이 분포까지 통제되지는 않는다. 경계 위치의 추가 진단에서는 길이 목록을 보존하고 순서를 섞어 재구성하는 대조군 등도 고려할 수 있으며, 이것도 완전한 의미적 oracle은 아니다.

### 6.4 유사도와 실제 utility

CLIP 유사도는 질문과의 관련성 추정치이며 QA에 대한 실제 기여도와 동일하지 않다. 계획서의 utility calibration은 이 차이를 검사하는 좋은 후속 실험이다. 프레임을 단순 삭제하면 budget 감소 효과가 섞인다. 구간 프레임을 같은 수의 대체 프레임으로 교체하는 등 budget을 유지한 개입을 정의하고, 정답은 사후 진단에만 사용한다. 정답 기반 기여도를 실제 selector 입력으로 보내지 않는다.

### 6.5 문서상 미완성 부분

PDF 17~19쪽에서 경계 교란, redundancy, token efficiency, utility calibration 수식과 일부 문장이 실제로 렌더링되지 않거나 잘려 있다. 특히 실제 contribution Δ_k와 평가 시간창의 정의를 문서 개정 때 명시해야 한다.

## 7. 평가와 실행 순서

1. 완료된 세 조건에서 BIN-TOP paired 차이와 선택 집중도·중복률을 분석한다.
2. 현재 dev 60영상으로 3절의 네 조건을 비교한다. 주 비교 D-C를 포함해 부정적인 결과도 모두 보고한다.
3. 4절에서 배분과 내부 선택의 효과를 분리한다. 다양성은 구간 없는 대조군과 함께 추가한다.
4. 구현·설정·주 비교를 고정한 뒤, 기존 dev와 원본 영상이 겹치지 않는 보류 평가 영상에서 확인한다. 현재 dev 결과는 이후 설계를 결정하는 데 사용했으므로 최종 확증 결과로 재사용하지 않는다.
5. B=8/16/32와 실제 비용으로 예산별 이득을 확인한다. 다른 QA 방식은 같은 방법 집합을 대상으로 별도 프로토콜로 평가한다.
6. complexity 및 caption은 앞선 병목 진단에 맞춰 추가한다. caption을 최종 QA에 넣는 실험과 선택 점수에만 쓰는 실험을 구분한다.

개발 중 여러 비교의 CI는 탐색적으로 표시한다. 보류 평가에서 복수의 주 가설을 검정한다면 다중 비교 처리도 사전 고정한다. 모델, QA 평가 규칙, 구간화, 선택기를 동시에 바꾸지 않는다.

이 설계가 목표로 하는 기여는 'event-aware 구성요소를 모았다'는 설명보다 구체적이다. 이벤트 구조가 도움이 되는 조건과, 배분·내부 선택·근거 관측·QA 중 실제 병목을 분리해 검증하는 것이다. 알고리즘의 선행연구 대비 신규성은 별도의 문헌 비교가 필요하다.
