# TMM 투고를 위한 이벤트 기반 프레임 선택 연구 계획

작성 기준일은 2026년 10월 4일이다. 연구 목표는 IEEE Transactions on
Multimedia 투고를 준비하는 것이며, **11월 초까지는 RTX 3060으로 예비
실험을 수행한다.** 11월 초를 투고 마감일로 해석하지 않는다.

현재 우선순위는 이벤트 구간화의 고유 기여와 답변 근거 보존 효과를 확인해
본실험으로 가져갈 방법을 결정하는 것이다. 아래 방법과 실험은 제안 단계다.
새 선택기 구현, 근거 주석, 추가 QA를 완료했다는 보고가 아니다.

## 저널 목표와 현재 근거

TMM은 기존 지식을 확장하는 독창적인 연구를 다루며, 공식 안내는 재현에
필요한 코드와 자료의 공개를 권장한다. 멀티미디어 이해 및 처리라는 주제는
범위에 부합하지만, 주제 적합성만으로 방법의 기여가 성립하지는 않는다.
이 문서의 데이터셋 수, 비교 방법 수, 일정은 **연구 설계 제안**이며 공식
TMM 채택 요건이나 채택 확률 추정이 아니다.
[TMM 공식 범위와 재현성 안내](https://signalprocessingsociety.org/publications-resources/ieee-transactions-multimedia),
[IEEE CASS의 TMM 설명](https://ieee-cas.org/publication/ieee-transactions-multimedia)

현재 20개 긴 dev 영상과 60문항의 320×320·32장 결과는 다음을 보여준다.
신뢰구간은 영상 단위 paired bootstrap 5,000회이며 보조 비교는 다중비교
보정 전이다.

| 비교 | 정확도 차이 | 95% 신뢰구간 | 현재 해석 |
|---|---:|---:|---|
| D와 Uniform | +4.44%p | +1.39~+8.06 | 이 개발 조건에서 전체 방식의 이득 |
| D와 균등 구간 C | +5.00%p | −1.11~+11.67 | 구간화 정책의 추가 효과는 불확실 |
| D Top-k와 C Top-k | +0.28%p | −3.33~+3.33 | 내부 Top-k 아래 분할 우위 미확인 |
| D Top-k와 D | 0.00%p | −6.11~+6.11 | CLIP Top-k의 평균 개선 미확인 |
| D의 32장과 16장 | +0.28%p | −3.06~+3.61 | 프레임 증가에 따른 개선 미확인 |

기존 16장 long holdout에서는 D와 Uniform의 차이가 −1.28%p
[−5.98,+3.28]였다. 이 결과와 동일 dev의 반복 탐색을 함께 공개한다.
개발셋의 양의 신뢰구간을 독립적인 일반화 검증으로 바꾸어 표현하지 않는다.
[32장 결과](../outputs/frame_budget32_long/handoff.json),
[기존 holdout 결과](../outputs/selector_compare320_holdout_long/handoff.json)

선택 계획에서 D의 실제 구간 수는 영상별 33~128개이고 중앙값은 128개다.
20개 중 13개 영상이 상한 128개에 도달한다. **60문항 모두에서 D32는
32개 구간에 한 장씩 배분한다.** 따라서 지금까지의 16→32 비교는 주로
관찰할 구간 수의 증가이며, 같은 구간의 여러 상태를 관찰하는 검증은 아니다.
이 사실 자체를 구현 오류라고 부르지는 않는다.

## 선행연구와 구별해야 하는 기여

Exa에서 세 조사축에 걸쳐 요청한 검색 결과는 총 40건이다. 중복을 포함한
검색 슬롯 수이며 40개의 고유 논문을 모두 정독했다는 뜻이 아니다. 공식
정책과 가까운 방법 및 근거 평가를 검토했으며 문헌조사의 완전성을 보장하지
않는다. 상세 비교는 [관련 연구 표](../exa-results/tmm-strengthening-2026-10-04/related_work.csv)에 있다.

| 연구 | 확인한 내용 | 우리 연구가 설명해야 하는 차이 |
|---|---|---|
| AKS, CVPR 2025 | 질문 관련성과 재귀적인 시간 분할을 결합한 고정 예산 선택 | 관련성과 시간 분산을 결합했다는 주장 이상의 차이 |
| WFS-SB, CVPR 2026 | 질문 관련성 신호의 wavelet 경계, 구간별 예산, 내부 MMR 선택 | 경계 검출기 교체를 넘어서는 근거 보존 또는 효율의 차이 |
| Video-Seer, TMM 2026 | 동적 구간화, 장면 중요도 기반 배분, 세밀한 관찰과 전역 관찰 | 계층적 장면 선택과 배분 자체를 새 기여로 주장하기 어려움 |
| QCA, ECCV 2026 | 균등 구간의 관련성·내용 변화량 기반 배분과 내부 다양성 | 내용 기반 경계의 추가 이득을 직접 증명해야 함 |
| E-VRAG와 FOCUS, 확인한 arXiv 버전 | 인접한 시각적 그룹, 불확실성 기반 탐색 등 | 연속 그룹이나 불확실성이라는 이름만으로 독창성을 주장하지 않음 |

WFS-SB는 현재 D와 구조가 특히 가깝다. 해당 논문의 원문은 관련성 신호에서
경계를 구하고 구간에 프레임을 배분한 뒤 다양성을 고려해 선택한다. 이 방법은
가장 먼저 재현 가능성과 공정한 직접 비교 조건을 확인할 대상이다.
[WFS-SB 원문](https://openaccess.thecvf.com/content/CVPR2026/papers/Chen_Wavelet-based_Frame_Selection_by_Detecting_Semantic_Boundary_for_Long_Video_CVPR_2026_paper.pdf)

Video-Seer는 저자 소속 기관의 논문 기록에서 TMM 게재와 초록을 확인했다.
정확한 전체 구현·코드 공개 상태는 확인되지 않았다. 초록만으로 완전한
알고리즘 중복을 단정하지 않는다.
[Video-Seer 게재 기록](https://researchportal.hkust.edu.hk/en/publications/video-seer-a-hierarchical-scene-selection-and-multi-view-analysis/)

현재 D의 경계는 CLIP 특징 변화로 만든 구간이다. 사람의 의미적 사건 경계와
일치한다는 별도 평가 없이 정확한 semantic event segmentation이라고
표현하지 않는다. 아래 기여 후보의 독창성도 아직 확정된 것이 아니다.

## 보강할 연구 질문과 기여 후보

핵심 질문은 **고정된 시각 입력 예산에서 내용 기반 구간을 활용하면 답변에
필요한 증거 집합을 더 잘 보존할 수 있는가**로 구체화한다. 질문과 비슷한
단일 이미지의 점수뿐 아니라, 필요한 상태·전후 관계가 실제 입력에 남는지를
측정한다. 정답률만으로 근거를 잘 골랐다고 추정하지 않는다.

| 기여 후보 | 입증할 내용 | 미리 가정하지 않을 내용 |
|---|---|---|
| 선택 실패의 정량적 분해 | 후보 누락, 구간별 배분 제약, 내부 선택, QA 모델 오류를 구분 | 모든 오류가 키 프레임 누락 때문이라는 가정 |
| 증거 보존을 목표로 한 선택 규칙 | 확인된 병목을 겨냥한 단일 규칙이 가까운 기존 방법보다 개선 | 새로운 이름이나 기존 요소 결합만으로 독창성이 성립한다는 가정 |
| 정확도와 근거 및 비용의 공동 검증 | 다른 영상·모델에서 근거 보존과 QA 이득, 전체 비용을 함께 설명 | QA 비용만으로 전체 시스템이 더 싸다는 주장 |

진단에서 같은 구간의 서로 다른 상태를 여러 장 봐야 하는 경우가 반복적으로
확인되면, 구간당 대표 프레임 하나 대신 소수의 상보적인 프레임 묶음에 예산을
배정하는 방법을 설계한다. 입력은 영상 특징과 질문으로 제한하고 정답·근거
주석은 넣지 않는다. 관련성·다양성 조합은 이미 선행연구에 있으므로, 단순
MMR 추가는 먼저 강한 대조군으로 사용한다. 구체적인 목적함수와 최적화는
관찰된 병목 및 WFS-SB 등과의 차이를 정리한 다음 고정한다.

근거 손실이 구간 배분에서 주로 발생하면 배분을 연구 대상으로 삼는다.
근거를 제공해도 QA가 계속 실패하면 선택기 개선만으로 해결될 문제인지
재평가한다. 이벤트 경계를 핵심 기여로 유지하려면 D와 C의 차이 또는
통제된 경계 실험에서도 이득을 보여야 한다.

## 사용할 자료와 평가 자료의 분리

현재 로컬 결과를 확인한 자료는 dev 60영상·180문항과 기존 long holdout
39영상·117문항이다. **이 99영상·297문항은 향후 수정안 개발에 사용된
자료로 관리한다.** 이미 본 holdout을 새 독립 시험셋으로 다시 명명하지 않는다.

900개 고유 MP4 이름을 포함한 아카이브가 있고 그중 801개에서 로컬 QA
결과를 찾지 못했다. 그러나 이는 외부 사용 이력, 정답 노출, 영상 무결성까지
검증한 미사용 시험셋 인증은 아니다. 새로운 manifest를 만들 때 원본 영상
ID 단위로 중복 및 파생 클립을 점검하고, 사용 이력과 품질 검사를 기록한다.
기존 `videomme_pilot_new` manifest는 원본과 동일하여 새 split이 아니다.

후보별 CLIP cosine, 경계와 선택 계획은 저장되어 있다. 재사용 가능한 전체
CLIP embedding 배열은 로컬 점검에서 발견하지 못했다. 다양성 기반 선택기나
다른 인코더를 비교하려면 특징을 다시 추출해 캐시하고 그 비용을 측정한다.
저장된 cosine을 원래의 고차원 특징처럼 취급하지 않는다.

## 답변 근거를 이용한 병목 진단

현재 사람 근거 자료는 사실상 856-1 한 문항의 후보 1035·1036에 한정된다.
이는 사후에 찾은 일부 reference이며 완전하거나 충분한 근거라는 인증은
없다. 과거 224 조건에서는 그 두 장만 제공한 QA도 0/6이었다. 이 사례를
선택만 고치면 정답이 된다는 증명으로 쓰지 않는다.

첫 주에는 기존 dev의 12개 영상에서 두 문항씩 총 24문항을 결과와 무관한
결정적 해시 순서로 뽑는 안을 제안한다. 영상의 질문 유형 분포를 확인하고
명단·seed·선정 규칙을 주석 전에 저장한다. 아직 명단을 생성하거나 동결한
상태는 아니다. 초기 6문항으로 주석 지침을 점검하면 해당 문항은 지침 개발용으로
표시하고, 변경 전후 지침 버전을 보존한다. 24문항은 예비 진단 규모이지
논문의 확증 평가 규모가 아니다.

주석자는 질문과 영상 및 정답 확인 자료를 보되 방법 이름·선택 프레임·QA
성공 여부는 보지 않는다. 가능하면 두 명이 독립적으로 주석하고 불일치를
조정한다. 한 명만 가능하면 그 한계를 보고하고 재검토 이력을 남긴다.

주석 항목은 다음과 같다.

- 시각 정보만으로 답할 수 있는지, 음성·자막·고해상도 글자가 필수인지.
- 충분한 증거의 시간 구간과 서로 대체 가능한 구간 또는 프레임 그룹.
- 여러 상태가 모두 필요한 경우 AND 관계, 대체 근거는 OR 관계.
- 2FPS 후보에 증거가 남는지, 실제 320×320에서 판독 가능한지.
- 전후 순서나 서로 다른 순간이 필요한지, 연속 영상 관찰이 필요한지.
- 주석의 완전성·확신도와 `unknown` 상태. 모르는 항목을 실패나 성공으로
  채우지 않는다.

주석 후 각 문항에 대해 다음을 계산한다. 모든 단계는 **알려진 주석 근거에
대한 판정**이며, 주석이 불완전하면 실제 가능성의 상한이라고 부르지 않는다.

1. **전체 후보의 가능성:** 전체 후보에서 예산 B장 이내로 충분한 근거 집합을
   구성할 수 있는가. 시간 순서·해상도 판독 조건도 적용한다.
2. **현재 배분의 가능성:** 같은 경계와 현재 구간별 quota를 지키면서 그 집합을
   구성할 수 있는가. 같은 구간의 두 필수 상태를 한 장으로 볼 수 있다고
   가정하지 않는다. 작은 정수 제약 문제로 검사할 수 있다.
3. **실제 선택의 성공:** 실제 선택된 B장이 알려진 충분 근거 집합을 포함하는가.
4. **QA 모델의 성공:** 충분 근거가 실제 들어간 문항에서 QA가 정답을 내는가.

2는 가능하지만 3이 실패하면 내부 선택에 개선 여지가 있다. 1은 가능하지만
2가 실패하면 배분 제약을 검토한다. 이 차이만으로 경계가 잘못됐다고 판정할
수는 없다. 구간 수가 같아도 경계가 바뀌면 길이·pooled score·배분도 바뀐다.
넓은 구간의 단순 overlap이 유리해지는 문제를 막기 위해 선택 구간의 총 시간
비율과 실제 선택 이미지의 근거 판독도 함께 보고한다.
각 단계는 판정 가능한 문항 수와 조건부 분모를 함께 제시한다. 한 프레임이
여러 근거 요구를 동시에 만족하는 경우도 허용하며, 불완전한 주석을 실패로
강제 분류하지 않는다.

추가 QA가 필요하면 사람이 표시한 근거를 넣는 조건을 **진단용**으로만
실행한다. 현재 quota 안에서 필요한 프레임만 교체하고 나머지 프레임은
결정적 규칙으로 유지한다. quota 때문에 불가능한 문항은 불가능으로 기록한다.
이를 실행 가능한 자동 선택기나 전체 성능표의 방법으로 섞지 않는다. 사람이
넣은 근거에서도 LLM이 틀릴 수 있어 수학적인 QA 정확도 상한도 아니다.

공개 자료로는 NExT-GQA가 답변의 시간적 근거를 평가하는 데 도움이 된다.
다만 긴 영상 벤치마크의 대체재는 아니다. 우리의 sparse-frame 근거 포함률과
해당 벤치마크의 구간 grounding 지표도 동일한 지표로 부르지 않는다.
[NExT-GQA 논문](https://openaccess.thecvf.com/content/CVPR2024/html/Xiao_Can_I_Trust_Your_Answer_Visually_Grounded_Video_Question_Answering_CVPR_2024_paper.html)

## 11월 초까지의 RTX 3060 예비 실험

아래는 10월 4일 기준 일정안이다. 각 단계의 불확실성이 해소된 다음 단계로
넘어가며, 양의 정답률이 나올 때까지 조건을 무한히 추가하지 않는다.

| 기간 | 작업 | 단계가 끝나면 남길 산출물 |
|---|---|---|
| 10월 4일부터 10일 | 선행방법 차이 정리, 24문항 표본 고정, 근거 주석 시작 | 관련 연구 표, 주석 지침과 표본, 데이터 사용 이력 |
| 10월 11일부터 17일 | 후보·quota·실제 선택의 근거 가능성 분석, 필요한 문항의 근거 주입 QA | 병목별 분포와 불확실성, 개선할 대상 하나 |
| 10월 18일부터 24일 | WFS-SB 재현 점검, 확인된 병목에 대응하는 선택기 한 개의 예비 비교 | 가까운 기준 방법과 비교, 실제 특징·선택·QA 비용 |
| 10월 25일부터 11월 초 | 필요한 소규모 구성요소 비교, 실패 사례 검토, 방법 및 본실험 설계 동결 | 본실험 진행 여부, 가설·프로토콜·코드 버전과 남은 한계 |

**먼저 볼 것은 내부 선택에서 개선할 여지가 있는지다.** annotation에서
그 여지가 거의 관찰되지 않으면 내부 Top-k 변형을 추가하는 우선순위를 낮춘다.
불확실한 경우 소수 사례만으로 병목이 없다고 확정하지 않고 주석을 넓힐지
판단한다. 가까운 기존 방법이 같은 오류를 이미 해결하면 해당 요소를 우리
독창성으로 주장하지 않고 다른 기여 또는 연구 범위를 검토한다.

구간당 한 장 제약이 병목으로 확인될 때만 다음 밀도 진단을 추가한다.
기존 D16 또는 C16이 선택한 **16개 구간을 고정**하고 구간마다 두 장을
배정해 32장으로 만든다. 모든 구간에 두 후보 이상이 있는지 먼저 검증한다.
내용 경계와 균등 경계에 똑같이 적용한다.

- 첫 선택 규칙은 기존 midpoint를 유지하고 그 구간에서 시간상 가장 먼 후보
  한 장을 추가한다. 동점이면 이른 프레임을 선택한다.
- 두 번째 규칙은 그 구간의 질문 관련성 상위 두 후보를 선택한다. 기존
  Top-1은 유지되며 동점이면 이른 프레임을 선택한다.

이를 기존 32구간 한 장 조건과 비교한다. 이는 **구간 커버리지와 내부 관측
밀도의 교환 관계를 보는 진단**이며 내부 선택 하나만 바꾼 인과 실험은 아니다.
기존 top8 집중 배분 실험과 관련된 후속 진단이지 새 알고리즘이라고 부르지
않는다. midpoint와 추가 프레임의 시간 거리만으로 실제 증거가 늘었다고
가정하지 않고 근거 주석으로 확인한다.
midpoint에서 먼 프레임은 무관한 끝 장면일 수 있고 Top-2는 거의 같은
인접 장면일 수 있다. 따라서 두 규칙의 음성 결과가 두 장 관찰의 무용성을
뜻하지는 않는다. 네 조건을 모두 기본 실행하기보다, 관찰된 실패 형태에
맞는 비교만 사전에 고정한다.

## 예비 QA 예산

현재 32장 QA의 호출당 중앙값 약 24.3초를 참고 단가로 쓴다. 아래 시간은
현재 Qwen 모델·320 해상도·네 선택지 likelihood 채점에서의 단순 환산이다.
다른 모델·인코더·질문 길이·채점 방식으로 일반화하지 않는다. 전처리와
모델 로딩, 실패한 호출 및 재시도는 별도다.

| 선택적으로 실행할 블록 | 신규 QA 상한 | QA 참고 시간 |
|---|---:|---:|
| 근거 주입 진단 최대 24문항 × 두 정책 × 6순서 | 288회 | 1.94시간 |
| 필요할 때 밀도 진단 60문항 × 네 조건 × 6순서 | 1,440회 | 9.72시간 |
| 가까운 기존 방법 한 개 60문항 × 6순서 | 360회 | 2.43시간 |
| 동결할 자동 선택기 후보 한 개 60문항 × 6순서 | 360회 | 2.43시간 |
| 네 블록을 모두 수행하는 경우 | 2,448회 | 16.52시간 |

이것은 **조건부 예산안**이며 실행 예약이나 전체 연구 시간 예측이 아니다.
근거 주입에서 두 정책은 현재 quota 유지와 같은 전체 예산 아래 quota 재배분
조건이다. 두 조건의 목적과 가능 문항을 구분한다. 현 QA 결과와 입력이 완전히
같은 경우만 엄격하게 재사용한다. 위 상한은 새 CLIP/BLIP 특징 추출, WFS-SB
이식·검증, 사람 주석 시간과 본실험 비용을 포함하지 않는다. 전처리 비중은
실측하기 전까지 미정으로 둔다.

현재 frozen 모듈과 출력은 그대로 보존한다. 향후 구현은 별도 실행기와 출력
폴더에서 수행하고, 16·32장 결과를 소스 해시와 원시 trial 검증 후 연결한다.

## 본실험에서 권하는 평가 구조

예비 실험에서 차별성과 개선 가능성이 확인된 뒤 본실험으로 확장한다. 아래
규모는 TMM의 공식 최소 요구량이 아니라 일반화 주장을 뒷받침하기 위한 제안이다.

| 축 | 권장 설계 |
|---|---|
| 긴 영상 QA | Video-MME의 설계에 사용하지 않은 영상과 LongVideoBench 등 별도 데이터셋 |
| 메커니즘 | 사람 근거 audit와 NExT-GQA 등 근거 주석 자료를 별도로 평가 |
| QA 모델 | 현재 모델과 다른 계열의 공개 모델을 포함해 최소 두 계열을 목표로 함 |
| 예산 | 우선 16·32장 또는 해당 모델의 동일 시각 토큰 예산, 64장은 필요성과 자원에 따라 추가 |
| 비교 방법 | Uniform·Global Top-k·Temporal-bin·C·기존 D·WFS-SB와 AKS 또는 QCA |
| 구성요소 | 새 요소 제거, 내용/균등 경계, 같은 배분과 다른 내부 선택, 필요한 상호작용 |
| 견고성 | 구간 수·후보 FPS·경계의 작은 이동·질문 유형·영상 길이·선택지 순서 |
| 효율 | 특징 추출, 질문별 선택, decode, QA, 최대 메모리 및 질문 간 재사용을 각각 측정 |

Video-MME 일부 영상을 평가하면 공식 전체 점수처럼 표시하지 않는다. 이미
관측한 영상이 포함된 전체 점수는 split별 결과와 사용 이력을 함께 보고한다.
다른 모델에서 32장이라는 숫자가 같아도 processor의 시각 토큰 수는 다를 수
있으므로 공정성은 모델별 동일 조건에서 확인한다.

선행방법은 원래 scorer·FPS를 포함한 재현과, 공통 scorer·후보 풀로 맞춘
선택 규칙 비교를 구분한다. CLIP으로 이식한 wavelet 선택기를 WFS-SB 원본
재현이라고 표기하지 않는다. 논문 표의 점수를 다른 QA 모델·해상도·채점
방식의 점수와 직접 비교하지 않는다. Video-Seer처럼 전체 pipeline이 다르면
모듈 비교와 시스템 비교의 비용 범위도 분리한다.

현재 6개 순서의 full-option likelihood 평균은 통제 실험의 지표로 유지한다.
본 성능표에는 선택한 벤치마크의 공식 평가 방식·프롬프트·출력 파싱 규칙을
확인해 적용하고, 방법 간 동일하게 고정한다. 두 채점 방식의 연결 검증은
개발 자료에서 수행하며 결과를 섞지 않는다. 선택지 순서 민감도는 별도
부분집합 분석으로 두어 본실험 비용을 관리할 수 있다.

## 통계와 연구 진행 판단

문항별 결과를 영상 안에 묶어 재표집한다. 선택지 순서 반복 여섯 개를 독립
표본 여섯 개로 계산하지 않는다. 조건 간 paired 차이, 효과 크기, 신뢰구간,
개선·하락 문항 수를 보고한다. 영상 길이별 분석은 주 비교와 탐색적 분석을
구분하며, 보고할 확증 비교의 다중비교 처리를 사전에 정한다.

수정 방법을 고정하기 전에 새 시험 자료의 결과를 확인하지 않는다. 주 비교는
Uniform뿐 아니라 가장 가까운 강한 방법 하나를 사전에 지정하고, 낮은 성능의
대조군으로 사후 변경하지 않는다. 필요한 표본 크기는 예비 자료의 영상 간
변동과 검출하고 싶은 실용적인 차이를 바탕으로 계획한다. 유의해질 때까지
표본을 추가하는 방식을 쓰지 않는다.

11월 초 판단은 다음 질문에 대한 근거를 남기는 것이다.

1. 내부 선택 또는 배분에서 실제 답변 근거가 반복적으로 손실되는가.
2. 새 자동 규칙이 그 손실을 줄이고 QA에서도 일관된 개선 가능성을 보이는가.
3. 같은 개선을 가까운 기존 방법이 이미 제공하는 것은 아닌가.
4. 추가 특징·선택 비용을 포함해 연구할 실용적인 이점이 남는가.

답이 불확실하면 해당 부분을 미해결로 남긴다. 이벤트 경계의 추가 이득이
확인되지 않으면 이벤트 분할의 일반적 우월성을 핵심 주장으로 고집하지 않는다.
근거 보존 분석이나 제한된 예산에서의 조건부 효과가 실제로 지지되는지에
따라 논문의 범위를 조정한다.
